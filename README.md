# Test Repo

[![CI](https://github.com/kostadindraganov/test/actions/workflows/ci.yml/badge.svg)](https://github.com/kostadindraganov/test/actions/workflows/ci.yml)

Hello, World! this is a test repository.

## What this repo is for

A sandbox for testing CodeDen agent and pull request workflows. It holds no application code.

## CI

The workflow in [`.github/workflows/ci.yml`](.github/workflows/ci.yml) runs on pull requests targeting `main`. It has a single `check` job that runs a placeholder step (`echo "checks passed"`).

## Contributing

1. Branch off `main`.
2. Make your change and open a pull request against `main`.
3. Wait for the CI check to pass.
